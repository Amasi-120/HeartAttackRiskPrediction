#  Heart Attack Risk Prediction

A Streamlit web application that predicts heart attack risk using an LSTM deep learning model.

## Features

- LSTM-based cardiac risk prediction
- Patient health data input
- Risk probability score
- Interactive Streamlit interface

## Technologies

- Python
- TensorFlow / Keras
- LSTM
- Streamlit
- Scikit-learn
